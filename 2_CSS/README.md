# Material de estudo — CSS

Este material foi criado para reproduzir os conceitos da seção de CSS
diretamente no VS Code.

A proposta é simples:

- `index.html` contém exemplos pequenos de cada conceito.
- `style.css` contém a aplicação e os comentários explicativos.
- Não existem arquivos separados para cada conceito.
- O Live Server serve apenas para visualizar o resultado.

## Arquivos

```text
css_estudo/
├── index.html
├── style.css
└── README.md
```

Abra o `index.html` com o Live Server.
