01

Fundamentos: como ler CSS

CSS = Cascading Style Sheets.

O CSS é uma linguagem de estilos. Ele diz ao navegador como os elementos HTML devem aparecer e se organizar.

.card {
color: blue;
}

Seletor

Indica quem receberá o estilo.

.card

Propriedade

Indica o que queremos alterar.

color

Valor

Indica como a propriedade será aplicada.

blue

Declaração

É o conjunto propriedade + valor.

color: blue;
Como estudar: leia o comentário do CSS → altere um valor → salve → observe → tente prever o próximo resultado.

Três formas de aplicar CSS

Inline

Fica diretamente no elemento HTML.

<p style="color:red">
Útil para demonstração, mas geralmente não é a melhor organização.

Internal

Fica dentro de <style> no HTML.

<style>
p { color: red; }
</style>

External

Fica em um arquivo .css separado.

<link rel="stylesheet"
href="style.css">
É o formato principal deste material.

Elemento

Seleciona todas as tags daquele tipo.

}

Pode ser reutilizada em vários elementos.

}

Identifica um elemento específico.

#card-especial {
    border: 2px solid purple;
}

Descendente

Seleciona um elemento dentro de outro.

.card p {
    font-size: 14px;
}

Seletores combinados

Este parágrafo está dentro de .selector-demo.

Outro parágrafo para comparar.

Regra prática: prefira classes para estilização. IDs são mais específicos e costumam ser mais difíceis de sobrescrever.

Cascade: quando duas regras disputam

p {
    color: blue;
}

p {
    color: red;
}

As duas regras têm a mesma especificidade. Nesse exemplo, a segunda aparece depois e vence.

Não decore o problema com !important.

!important altera a prioridade de uma declaração. Pode ser útil em casos específicos, mas usar em excesso torna o CSS difícil de manter.

Background

Imagem + gradiente + posicionamento

O fundo deste bloco usa background-image, background-size, background-position e background-repeat.

background-color

Define uma cor de fundo.

background-color: #fff;

background-image

Coloca uma imagem ou gradiente no fundo.

background-size

Controla a posição da imagem, como center.

Background ≠ <img>: background faz parte da apresentação do elemento. Uma imagem inserida com <img> é um elemento do conteúdo.

Box Model — entenda a caixa

Todo elemento HTML pode ser pensado como uma caixa. A ordem mental mais importante é:

CONTENT → PADDING → BORDER → MARGIN
MARGIN
BORDER
PADDING
CONTENT

Content

Texto, imagem ou conteúdo interno.

Padding

Espaço interno entre conteúdo e borda.

Border

A borda da caixa.

Margin

Espaço externo ao redor da caixa.

content-box × border-box

content-box

width: 180px
padding: 20px
border: 5px

border-box

width: 180px
padding: 20px
border: 5px
Por que border-box é tão usado?

Com border-box, o width informado já considera conteúdo + padding + border. Isso torna o dimensionamento mais previsível.

Shorthand de padding e margin

padding: 20px;todos os lados
padding: 10px 30px;vertical | horizontal
padding: 10px 20px 30px;top | horizontal | bottom
padding: 10px 20px 30px 40px;top | right | bottom | left

Margin collapse — um conceito importante

Elemento A — margin-bottom: 30px
Elemento B — margin-top: 40px

Em alguns layouts verticais, margens de elementos em fluxo podem colapsar, fazendo com que o espaço final não seja simplesmente a soma das duas margens. Flexbox e Grid não usam esse mecanismo da mesma forma entre seus itens.

Position — um dos conceitos mais importantes

Position não significa simplesmente "mover".

A propriedade position define o modelo de posicionamento do elemento e muda a forma como ele participa do fluxo e/ou encontra sua referência.

static comportamento padrão
relative mantém seu espaço e pode ser deslocado
absolute sai do fluxo e procura um containing block
fixed normalmente relacionado à viewport
sticky participa do fluxo e pode "grudar"

11.1 static

position: static
Outro elemento continua no fluxo.

top, right, bottom e left não deslocam um elemento static.

11.2 relative

position: relative
top: 20px
left: 20px
O espaço original continua reservado.
Insight: relative é muito usado no pai para criar uma referência para um filho absolute.

11.3 absolute

absolute

Este pai possui position: relative. Por isso o filho absoluto usa esse contexto como referência.

Absolute sai do fluxo normal.

Ele não reserva espaço como um elemento normal. Para encontrar sua referência, procura um ancestral adequado como relative, absolute, fixed ou sticky. Se não houver, o containing block inicial pode ser usado.

11.4 O padrão mais usado: relative + absolute

NOVO

Card com badge

O card é relative e o badge é absolute. 

.card {
    position: relative;
}

.badge {
    position: absolute;
    top: 10px;
    right: 10px;
}

11.5 fixed

O botão "Topo" no canto inferior direito usa position: fixed. Role a página para perceber que ele permanece preso à viewport.

11.6 sticky

STICKY — role dentro desta área

O título começa em seu lugar normal e, ao atingir top: 0, fica preso dentro do seu contexto.

Z-index — camadas e sobreposição

Quando elementos podem se sobrepor, z-index ajuda a controlar a ordem de empilhamento.

Regra simplificada para começar: maior z-index → camada mais acima, desde que a comparação esteja acontecendo no contexto adequado.

z-index: 1
z-index: 5
z-index: 10
Stacking context:

z-index: 100 não significa que o elemento sempre ficará acima de qualquer elemento com z-index: 10. A comparação depende dos stacking contexts.

Responsividade — Media Queries

Uma interface responsiva adapta o layout a diferentes tamanhos de tela. @media permite aplicar regras condicionais. 

@media (max-width: 800px) {
    .grid {
        grid-template-columns: 1fr;
    }
}

16

Desafio final — não altere o HTML

Faça todos os exercícios somente no style.css.

  1. Troque as cores do material.
  2. Altere o Box Model e compare content-box e border-box.
  3. Troque um layout Flexbox para coluna.
  4. Transforme um exemplo Grid de 3 para 2 colunas.
  5. Mude a posição do badge.
  6. Teste display: none e visibility: hidden.
  7. Coloque um filho como absolute e remova o relative do pai.
  8. Depois coloque o pai novamente como relative.
  9. Altere os z-index e observe a sobreposição.
  10. Teste position: sticky com valores diferentes de top.
  11. Altere flex-direction, justify-content e align-items.
  12. Faça a página funcionar melhor em uma janela pequena.
